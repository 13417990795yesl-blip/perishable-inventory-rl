# 相对价格模型修订与 DP 重算（2026-10-14）

## 本次明确选择

用户要求采用相对价格方案。需求指数中使用 `u_j=p_j/p_list`，其中实际售价 p_j∈{10,7,5}、原价 p_list=10，因此 u_j∈{1,.7,.5}。数值敏感度仍为 b=(.3,.5,.7)：

`lambda_j = exp(-b_j*u_j)/(1+sum_k exp(-b_k*u_k))`。

销售收入仍为 `sum_j p_j*sales_j`，不使用 u_j 作为收款价格。`configs/base_config.yaml` 显式保存 `demand_price_basis: relative`。

这次保留 b 的数字而改变其价格单位，是用户选定的模型解释；不等同于纯单位换算，也尚未通过作者代码核实。不能仅凭得到正利润就证明它与作者实现一致。

## 保留的参数与机制

平均潜在需求 4、CV=.5、Gamma shape=4/scale=1、原价10、折扣0/30/50、四类成本1/3/5/7、保质期3、正交货期1、qmax10、gamma=.99和365步评估均保持原配置。

仍采用通常的一期交货和三维到货后库存状态；保留不购买选项、缺货不替代和连续销量。没有用其他经济参数补偿利润。实际动作集合仍为297种。
