# Phase 4 DP 具体计算方案

本文记录此前实际价格需求模型的计算方案与结果。当前用户选定的相对价格版本及重算结果见 `relative_price_revision.md`；Gamma积分、库存网格和收敛验收方法沿用本文方案。

本方案是用户授权补充的数值实现，基于已验证的连续 Environment。论文提供价值迭代方程，但未给出可直接复用的需求取整、库存网格、完整转移概率计算和收敛阈值。因此下列数值选择属于复现约定，不声称与作者代码完全相同。

## 1. 模型和状态

沿用用户选定的通常一期交货：本期订货在下一期销售前到货。当前 DP 支持 M=3、L=1；其他维度显式拒绝，不套用此求解器。

状态为到货后的 `[x_1,x_2,x_3]`，按新鲜到最老排列。订单为整数 0…10，所以正常到货后的 `x_1` 必为整数；`x_2,x_3` 可为小数。每组最多 10 件，因为每次到货构成单独一批，年龄转移不会合并不同年龄组。

实际 Environment 不对需求、销量或剩余库存取整。DP 仅在 `x_2,x_3` 的价值函数表示上使用网格。当前候选配置见 `configs/dp_config.yaml`，最终通过的细化结果另行记录。

均匀网格 1、0.5、0.25 的初步细化未通过：最大公共状态价值变化分别约 27.91、23.99。初步记录保留在 `results/logs/uniform_preliminary_phase4_validation.json`，不把小 Bellman 残差误认为网格已经足够细。

后续方案在 [0,2] 加密，(2,10] 使用 0.25 间距。中间验证比较 1/16、1/32、1/64；因为 1/32 与 1/64 策略在连续模拟中仍有可分辨的利润变化，又验证 1/32、1/64、1/128。最终配置候选为 1/128：289 个剩余库存节点，`11×289²=918,731` 个状态。网格保留全部整数节点，另将外侧间距从 0.25 缩小至 0.125 检查。

## 2. 完整动作

订货量 11 种、每个年龄折扣索引 3 种，共 `11×3³=297` 种动作。折扣 0%、30%、50% 对应实际价格 10、7、5；全部动作保留，没有实现 ar-DP 的动作删减。

MNL 使用实际售价：

`lambda_j = exp(-b_j*p_j) / (1 + sum_k exp(-b_k*p_k))`。

`b=(0.3,0.5,0.7)`；分母常数 1 为不购买选项。各年龄共用同一个总需求 D，不能把年龄需求当成相互独立的 Gamma 随机变量。缺货后不重分配需求。

## 3. Gamma 完整概率与矩

`D ~ Gamma(k,theta)`，`k=1/CV²=4`，`theta=mean*CV²=1`。

任意需求区间 `[a,b)` 的概率为 `F_k(b/theta)-F_k(a/theta)`；b 可为无穷，不人为设置需求最大值。上尾使用生存函数之差，避免 `1−1` 的浮点消减。

分段计算使用截断矩：

`M_r(a,b)=E[D^r * 1(a<=D<b)]`

`=theta^r * Gamma(k+r)/Gamma(k) * [F_(k+r)(b/theta)-F_(k+r)(a/theta)]`。

使用 r=0、1、2 的矩，足以精确积分分段二次的双线性插值权重。使用 SciPy 1.13.1 的 `gammainc/gammaincc` 实现，并用独立 `quad` 积分验证，包括极小的上尾概率。

资料：[SciPy gammainc](https://docs.scipy.org/doc/scipy/reference/generated/scipy.special.gammainc.html)、[gammaincc](https://docs.scipy.org/doc/scipy/reference/generated/scipy.special.gammaincc.html)。

## 4. 单期奖励的解析期望

销售 `Y_j=min(x_j,lambda_j D)`，剩余 `R_j=x_j−Y_j`。不购买选项不计缺货罚款。

`E[Y_j]=lambda_j*mean*F_(k+1)(x_j/(lambda_j*theta)) + x_j*Q_k(x_j/(lambda_j*theta))`。

若 lambda_j=0，则期望销量为 0。然后按实际 Environment 的账目计算：

`E[r]=sum_j p_j E[Y_j] − c_o q − c_h(E[R_1]+E[R_2]) − c_l(mean*sum_j lambda_j−sum_j E[Y_j]) − c_p E[R_3]`。

本期新到货不在本期持有成本中；最老剩余报废，不再收持有费。期望奖励由解析公式计算，不使用一次随机样本代替。

## 5. 状态转移与插值概率

下一期实际状态为 `s'=(q,R_1,R_2)`，R_3 报废。

若剩余量在网格相邻节点 g_i、g_(i+1) 之间，则价值函数在这一轴上的权重为 `(g_(i+1)−R)/(g_(i+1)−g_i)` 与 `(R−g_i)/(g_(i+1)−g_i)`。两个轴采用权重乘积。

用 `P_h(z|s,a)=E[w_z(R_1,R_2)]` 作为投影 Bellman 方程的转移概率。它可以理解为价值插值诱导的有限 MDP；实际模拟中不随机舍入库存，也不创造或删除货物。

在 `D=(x_j−g_i)/lambda_j` 处切分需求区间。每段的插值权重为二次多项式，使用上述 Gamma 矩进行解析积分，包含最后的无限区间。两个年龄的需求相关性由同一个 D 保留。

概率行必须非负且和为 1；仅允许清理浮点舍入误差：清理前最小项不得小于 −1e−10、概率和误差不得超过 1e−9，否则停止。微小负数截为 0 后归一化，清理前误差保存到报告。只删除浮点值已经为 0 的稀疏项，不设置概率剪裁阈值。

## 6. Value iteration 和可保证的精度

`V_0=0`，`gamma=0.99`。

`T_h V(s)=max_a [E[r(s,a)] + gamma*sum_z P_h(z|s,a)V(z)]`。

全部动作均参与最大化；利用“最老库存不进入下一期、订货成本为线性”复用计算，不删动作。小模型上已用逐状态逐动作穷举核对这种计算分解。

最多迭代 5,000 次。普通 VI 支持相邻迭代最大变化不超过 1e−7 的停止条件；最终运行采用常数平移加速，并独立计算原方程的最终 Bellman 残差 `rho=||T_h V−V||_infinity`。

加速不改变 Bellman 方程。因为 `T_h(V+c)=T_h(V)+gamma*c`，令 `delta=T_h V−V`，每次更新为：

`V_new=T_h V + gamma*(min(delta)+max(delta))/(2*(1−gamma))`。

由单调性，原方程在 V_new 上的残差不超过 `gamma*(max(delta)−min(delta))/2`。该上界小于 1e−7 后，再显式计算残差核实。单状态问题和小规模模型用普通 VI／策略线性方程交叉验证；原始普通 VI 的结果与计时另保留在日志中。

实际最后一次价值数组变化可能大于 1e−7，因为加速包含常数平移；验收的是原 Bellman 残差。收敛 CSV 记录每次更新前的 Bellman 残差，不将它误标成平移后的价值变化。

投影模型上的价值误差上界为 `rho/(1−gamma)`，目标不超过 1e−5。这个上界不包含网格误差，不是原连续模型的最优性证明。

提取完整策略表；数值完全相等时，价格索引字典序和较小订货量优先。配置、价值数组、动作策略、延续价值表保存为 NPZ checkpoint；加载后无需重新构造转移矩阵即可执行策略。

## 7. 连续 Environment 中的策略执行

实际观察到的小数库存不被取整。即时奖励期望根据真实库存解析计算；第二年龄的延续价值在相邻库存节点之间线性插值，然后比较全部 297 个动作。正常运行的第一年龄为整数到货；人为重置成小数第一年龄的状态不属于当前 DP 支持域。

DP 求解目标为无限期折扣价值，论文实验指标为 365 步不折扣总利润；分别记录，不能把二者直接当成同一个数。后续 DP/ar-DP/PPO 均需在同一连续 Environment、相同初始条件和需求种子上评估 365 步利润。

## 8. 验证标准

- 程序：保留 Environment 27 个测试，新增积分、概率质量、均值与联合矩、全动作备份、直接策略线性方程、checkpoint 和非均匀网格测试。
- 数值积分：解析计算与独立 `quad` 对照；验证奖励时积分现有 Environment 的逐期账目。
- 网格：公共状态上比较价值和策略；工程标准为相邻两次细化的最大价值变化不超过较细网格公共状态价值绝对规模的 0.1%。此标准是灵敏度筛查，不是严格连续模型误差上界。
- 实际策略：初步每层使用相同 20 个种子 42…61；最终每层使用相同 100 个种子 42…141，分别从空库存和非网格库存 `[3,2.3,1.7]` 出发运行 365 步，记录不折扣／折扣利润和订货量。最后两层策略的成对利润变化，用 Student t 构造近似 95% 区间，要求 `abs(样本平均变化)+区间半宽 <= 0.5`。0.5 是本项目自选的年度利润稳定性标准，小于 baseline 一次单位持有成本 1；不是论文规定值，也不是总体误差的严格保证。此处额外检查避免仅凭价值规模归一化后的比例很小就采用网格。
- 时间：CPU 运行，OMP／OpenBLAS／MKL 线程数设为 1；分别报告构造转移与奖励的时间、迭代求解时间。GPU 不参与当前 DP。

结果与方案状态以 `results/logs/phase4_validation.json` 为准；当前最终方案已通过上述标准。投影 Bellman 方程精度、经验网格稳定性、作者数值复现是三个不同结论，不合并声称。

| 公共状态动作一致率 | 99.99158% |

最后两层策略的 100 个相同种子成对年度利润差：两种初始库存的平均差均约 −0.08614，标准误 0.19966，近似 95% 区间均为 [−0.48231,0.31003]。`abs(均值)+区间半宽=0.48231 < 0.5`，通过预设标准。单次 episode 的最大差仍约 9.014；标准针对平均年度利润，不保证每条随机轨迹的结果接近。

最初 1/32→1/64、20 种子的年度利润平均差约 +1.887，标准误 0.729，促使继续细化和增加种子数量。保留这次中间验证，不将它作为最终通过依据。

空库存的最终投影无限折扣价值为 −45.25716；实际连续 Environment 的 100 次 365 步不折扣利润平均 −143.67606、标准误 5.20092。两者不可直接相减作为误差或最优性 gap。当前负利润是本模型下的输出，不证明匹配作者结果。更改价格单位、缺货处理或需求解释会改变模型，需要另行记录并重新验证；本阶段没有为数值对齐而修改这些约定。

checkpoint 为 `checkpoints/dp_grid_0p0078125.npz`；原始日志、逐次收敛 CSV、网格灵敏度表、具体模拟利润全部保留。最终阶段归档为 `checkpoints/phase4_project.tar.gz`。

## 9. 复运行

```bash
cd /data1/yesiliang/perishable_inventory_rl
source .venv/bin/activate
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
python -m pytest -q tests
python -m algorithms.dp
python -m experiments.validate dp
```

`algorithms.dp` 读取 `configs/base_config.yaml` 和 `configs/dp_config.yaml`；`experiments.validate dp` 重做三层网格、外侧网格和连续策略审计。已有 checkpoint 与当前配置一致时可使用 `--reuse-solved` 复用已完成的网格求解，但仍执行外侧检查和策略模拟。
