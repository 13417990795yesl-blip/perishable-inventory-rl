# 建模核对与未决点

依据：论文第 3 节、5.2 节、Tables 3–5；用户提供的 reproduction protocol。本文档不将协议中的简略文字视为已经验证的论文公式。

1. **库存维度**：正文 Eq. (6) 写为 l−1 个在途组和 m−1 个年龄组，但同页称维度为 m+l−1；实验明确称 l=1、m=3 对应四维，并使用三维价格敏感度。协议指定 `[age_1, age_2, age_3, transit]`。由于用户后来选择常规一期交货并允许调整在途定义，最终采用 M 个年龄组加 L−1 个在途组：baseline 三维。这里是有记录的用户选择，不声称解决了作者正文矛盾或核实了作者代码。
2. **需求**：Eq. (1) 为 MNL 权重，分母含常数 1（不购买选项）；Eq. (2) 为 `d_j=d*lambda_j`。Gamma 总需求参数由 mean=4、CV=.5 推出 shape=4、scale=1。论文未说明连续需求/年龄需求的取整规则或 DP 离散化；实际 Environment 保留连续值。Phase 4 按用户授权补充价值插值网格与完整 Gamma 分段积分，具体方案及验证结果见 `dp_computation_scheme.md`。
3. **价格**：协议及实验将折扣0/30/50转换为实际售价10/7/5；需求方程p与“折扣设置”描述存在符号混用。历史版本将实际售价代入MNL指数；用户随后明确要求切换为相对价格方案，当前使用实际售价/原价（1/.7/.5）计算需求效用，收入仍用10/7/5。数值敏感度保持(.3,.5,.7)，属于对价格单位的重新解释，尚未核实作者代码。历史数据完整保留，当前结果见`relative_price_revision.md`。
4. **缺货**：公式没有随库存改变 MNL 分母，也未明确缺货后的替代购买。保持所有年龄选项的原始权重，缺货需求计为 lost sales；不自行重分配需求。不购买选项不属于 lost sales。
5. **交货时序（用户已明确）**：用户选择通常的一期交货，允许调整在途状态定义。`q_t` 在 `t+L` 可销售，状态观察在本期到货之后；因此保留 M 个年龄组和 L−1 个尚未到货组。L=1 时状态为三维，L=2 时为四维。step 期末到货是下一期营业前到货，L=1 时接收本期订单，L>1 时接收管道中最早到货的订单。之前提到的 t+2 是“本期新订单进入一个额外在途槽、下期卖完才到货”的实现解释，协议本身并不必然要求这种额外延迟。已排除此解释。
6. **持有费**：Eq. (9) 的口径是扣除报废后剩余的在架库存；不对新到货及在途收取本期持有费，已单独测试奖励分解与数量守恒。
7. **时间上限**：365 步是实验 episode 长度；Gymnasium 中作为 truncation，而非库存耗尽 termination。
8. **后续实验**：协议目录列 Case 3，但优先级为 Cases 1/2/4，因此均保留占位。后续需避免把 DP 折扣无限期价值与 365 步总利润直接比较。最优性差距按协议/论文 Eq. (18) 带符号计算，论文表中正号需另行核对。

当前 Environment 将年龄组数量按实验/协议取 M，交货时序按用户选定的常规含义实现。连续需求、实际价格代入 MNL、缺货不替代等均是公开记录的复现解释，不声称已经核实作者代码。Environment 与 Phase 4 投影 DP 数值方案已通过各自验收；仍不能宣称精确复现作者的论文数值。
